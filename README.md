# Alvina Hospital Automation

Alvina Hospital Automation is a comprehensive software solution designed to streamline hospital management processes. This application automates various administrative tasks, enhancing efficiency and improving patient care.

# Features

- Announcements Page
  Displays announcements from the hospital.
  Click on any announcement to view its details in a pop-up window.
- Appointment List
  Lists all appointments with details such as date, time, branch, doctor, and patient ID.
  Click on an appointment to view its details in a pop-up window.
- Branch Management
  View, add, update, and delete hospital branches.
  Double-click a branch to view and edit its details.
- Doctor Detail Page
  Displays the doctor's personal information and their appointments.
  View and update appointment details, including patient complaints.
- Doctor Panel
  Manage doctor records: add, update, or delete doctors.
  View the list of all doctors and their details.
- Main Page
  Entry point for the application with login options for patients, doctors, and secretaries.
- Patient Detail Page
  Displays patient's personal information and appointment history.
  Allows patients to book appointments and update their information.
- Secretary Detail Page
  Manage appointments and announcements.
  Create new appointments and announcements.
  Access doctor and branch management panels.

# Installation

- Clone the repository
  git clone https://github.com/MehmetGulbahar/alvina-hospital-automation.git
- Open the solution file (.sln) in Visual Studio.
- Restore the NuGet packages and build the solution.
- Update the database connection strings in DatabaseConnection.cs to match your database setup.
- Run the application.

# Usage

- Login
  Patient Login: Patients can log in to view and manage their appointments.
  Doctor Login: Doctors can log in to view their schedules and patient complaints.
  Secretary Login: Secretaries can manage hospital appointments, doctors, and branches.
- Manage Records
  Announcements: View, add, and update announcements.
  Appointments: View and manage appointment details.
  Branches: Add, update, and delete hospital branches.
  Doctors: Add, update, and delete doctor records.
